# Экран «Автовыгрузка через CRM систему» — интеграция

Готовый файл экрана: `lib/pages/profile_menu/crm_feed/crm_feed_screen.dart`
(скопируй его в проект по этому пути)

Осталось 3 маленьких правки, чтобы экран открывался.

## 1. Зарегистрировать роут — в lib/app/routes.dart

**Добавить импорт** (рядом с другими, вверху файла, после строки 12):
```dart
import 'package:lidle/pages/profile_menu/crm_feed/crm_feed_screen.dart';
```

**Добавить роут** в Map маршрутов (после строки 92, рядом с privacy_settings):
```dart
    '/crm_feed': (context) => const CrmFeedScreen(),
```

## 2. Пункт в меню настроек — в settings_screen.dart

После блока «Конфиденциальность» (`_settingsItem(... 'Конфиденциальность' ...)`)
добавить:
```dart
                _settingsItem(
                  SvgPicture.asset(
                    'assets/profile_menu/settings/layout-alt-02.svg',
                    color: Colors.white,
                    width: 21,
                    height: 21,
                  ),
                  'Автовыгрузка через CRM систему',
                  onTap: () => Navigator.pushNamed(context, '/crm_feed'),
                ),
```
(иконку layout-alt-02.svg использую как заглушку — можно заменить своей)

## 3. Кнопка в сетке категорий — УЖЕ СДЕЛАНА

Блок в category_selection_screen.dart ты уже добавила (ведёт на '/crm_feed').

## Проверка

После правок:
1. `flutter pub get` (на всякий случай)
2. Собрать приложение
3. Открыть экран двумя путями:
   - через сетку категорий (синий блок внизу)
   - через Профиль → Настройки → Автовыгрузка через CRM систему
4. Вставить ссылку фида, нажать «Подключить и запустить»
5. Проверить, что фид появился в списке ниже

## Что делает экран

- **GET /v1/me/crm-feeds** — показывает подключённые фиды
- **POST /v1/me/crm-feeds** — подключает фид по ссылке (feed_url)
- **DELETE /v1/me/crm-feeds/{id}** — удаляет фид
- Токен берётся из TokenService.currentToken (как в других экранах)
- Заголовки платформы добавляет ApiService автоматически
